# Space Cleanup

Space Cleanup is a small space arcade game where you fly a ship around space and clean up dangerous stuff. Try to stay alive for as long as you can and beat your high score.

## Description

In Space Cleanup you are a cadet flying a little spaceship through space. You have to move around hazards and collect things while trying not to crash. The game has a retro space style with stars planets explosions and cool sounds. You can earn stars and gems and use them to upgrade your suction power boost speed and shield. There is also a daily bonus and your best score is saved in the browser.

It is made with React and TypeScript and runs in a web browser.

### Dependencies

You need these things to run the project:

- Windows 10 or newer or another operating system that can run Node.js
- Node.js 18 or newer
- npm
- A modern web browser like Chrome Edge or Firefox

### Installing

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open a terminal in the project folder.
4. Install the project packages:

```bash
npm install
```

No changes to the source files are needed before running it.

### Executing program

1. Start the development server:

```bash
npm run dev
```

2. Open this address in your browser:

```text
http://localhost:3000
```

3. Press the launch button to start a mission. You can also press Space or Enter on the home screen.

4. To check that the project builds correctly you can run:

```bash
npm run build
```

## Help

If the page does not open make sure the terminal is still running and that port 3000 is not being used by another program.

If the game looks stuck try refreshing the page. Your high score is saved in the browser but using the reset option will clear your score and upgrades.

To stop the development server press `Ctrl + C` in the terminal.

```bash
npm run lint
```

The command above checks the TypeScript files for errors.
